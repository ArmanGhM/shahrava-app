## ✨ ویژگی‌ها

<div align="center">
<table>
<tr>
<td width="33%" valign="top">

### 🎨 هویت بصری پویا
- **هر شهر = یک تجربه بصری یکتا**
- پالت رنگی اختصاصی (`tehran`, `tokyo`, `paris`, ...)
- الگوی SVG منحصربه‌فرد (گره‌چینی، ساکورا، خطوط آرت‌دکو...)
- اتمسفر صوتی با Web Audio API
- گردی و انحنای کارت‌ها همراه با تم

</td>
<td width="33%" valign="top">

### 📊 مصورسازی D3.js
- **نمودار اقلیمی** — دما و بارش ۱۲ ماه
- **رشد جمعیت** — از ۱۹۵۰ تا ۲۰۲۴
- **کره زمین سه‌بعدی** — Orthographic با خشکی TopoJSON
- **رادار مقایسه** — ۶ بُعد بین دو شهر
- **همه تعاملی** با tooltip و hover

</td>
<td width="33%" valign="top">

### 🌍 داده‌های زنده
- **آب‌وهوا:** Open-Meteo API (رایگان، بدون کلید)
- **دانشنامه:** Wikipedia Action API
- **جستجوی جهانی:** Nominatim (rate-limited)
- **نقشه:** OpenStreetMap + Leaflet
- **پرچم و کشور:** FlagCDN + REST Countries

</td>
</tr>
<tr>
<td width="33%" valign="top">

### 🎯 تجربه کاربری
- **PWA Installable** — نصب روی موبایل
- **دوزبانه کامل** — فارسی RTL + English LTR
- **تم تاریک/روشن** — با FOUC prevention
- **Mobile-optimized** — تشخیص خودکار دستگاه ضعیف
- **Toast notifications** — بازخورد لحظه‌ای

</td>
<td width="33%" valign="top">

### ♿ دسترسی‌پذیری
- **ARIA کامل** — `role="dialog"`, `aria-modal`
- **Focus-trap** — Tab در مودال می‌چرخد
- **Focus-restore** — بازگشت فوکوس به دکمه اصلی
- **Keyboard shortcuts** — `Ctrl+K`, `Escape`
- **Skip-link** — پرش به محتوای اصلی
- **Color-scheme aware**

</td>
<td width="33%" valign="top">

### ⚡ عملکرد
- **Lazy chunks** — D3 و Leaflet جدا
- **LRU cache** — placeholderها
- **Event delegation** — بدون rebind
- **Debounced search** — ۲۸۰ms
- **Rate-limit** — Nominatim policy
- **SVG placeholders** — بدون وابستگی شبکه

</td>
</tr>
</table>
</div>

## 🏙 شهرهای موجود

<div align="center">

| 🌍 قاره | 🏙 شهرها | 🎨 تم رنگی |
|:--------:|:---------|:------------|
| **خاورمیانه** | تهران، اصفهان، دبی، استانبول | 🟢 فیروزه‌ای، 🔵 لاجوردی، 🟡 طلای کویر |
| **آسیا** | توکیو | 🔴 قرمز نئونی، 🩵 آبی سایبر |
| **اروپا** | پاریس، لندن، رم، بارسلونا | 🥇 شامپاین، 🔴 سلطنتی، 🟤 تراکوتا |
| **آمریکا** | نیویورک، ریو دو ژانیرو | 🔵 آبی امپایر، 🟢 زمرد گرمسیری |
| **آفریقا** | قاهره | 🟡 طلای فراعنه |
| **اقیانوسیه** | سیدنی | 🔵 آبی پاسیفیک |

</div>

## ⚡ نصب و راه‌اندازی

### 📋 پیش‌نیاز
- **Node.js** ۲۰ یا بالاتر → [دانلود](https://nodejs.org)
- **npm** (همراه Node نصب می‌شود)
- **Git** → [دانلود](https://git-scm.com)

### 🚀 گام‌های نصب

```bash
# 1. Clone the repository
git clone https://github.com/ArmanGhM/shahrava-app.git
cd shahrava-app

# 2. Install dependencies
npm install

# 3. Start development server
npm run dev
